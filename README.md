## 📋 Trabalho Proposto 🏞️🛥️⚓
**Jogo de Batalha Naval** 
1. Jogo de batalha naval do jogador contra o computador
2. Deve haver dois tabuleiros: um do jogador e outro do computador, ambos de 10 x 10
posições
3. Cada um dos participantes possui 5 embarcações. Cada uma ocupa uma única posição
no tabuleiro
4. No início de cada partida, o jogador e o computador devem determinar as posições de
suas embarcações
5. Durante a partida deve ser mostrado o tabuleiro do adversário, indicando posições já
utilizadas: água ou embarcação afundada
6. Cada jogador tem direito a dar um tiro por vez. Caso acerte uma embarcação, tem
direito a dar outro tiro
7. O vencedor é aquele que conseguir afundar todas as embarcações do adversário
8. O programa deve permitir, através de um comando especial, que o jogador veja o
tabuleiro do computador (para testes)

## 🛠️ Implementação
- O programa foi implementado em C, utilizando vetores para armazenar os dados de alunos e responsáveis.
- Foi utilizada a função `scanf` para entrada de dados e `printf` para exibição.
- A lógica de associação entre alunos e responsáveis foi feita com base nos alunos menores de idade.

## 👨‍💻💻 Opções Oferecidas

descrevendo todas as opções oferecidas pelo sistema ao
usuário.

O projeto implementa as seguintes funcionalidades:
1. Popular um vetor de 100 alunos com uma estrutura de repetição.
2. Mostrar a quantidade de alunos menores de idade cadastrados.
3. Criar um vetor de responsáveis e associá-los a alunos menores de idade.
4. Permitir alterações nos dados dos responsáveis.
5. Exibir cada aluno e, se menor de idade, seu respectivo responsável.
6. Mostrar os percentuais de alunos maiores e menores de idade.
7. Mostrar o percentual de alunos associados a cada responsável.
